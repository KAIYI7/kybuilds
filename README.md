# kybuilds

Source for [kybuilds.com](https://kybuilds.com), the personal site of Lee Kai Yi.

Static site built with [Astro](https://astro.build).

```sh
npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # output in dist/
```

Projects are Markdown files in `src/content/projects/`. Screenshots live in `public/projects/`.
